Town seal for the dashboard header
==================================

Drop the Town of Oro Valley's official seal here as:

    town-seal.png

(ask the Communications office for the approved artwork). The app shows it at
40px square in the top bar and on the empty "choose a meeting" screen, so a
square PNG of at least 120x120 pixels with a transparent background looks best.

When this file is absent the app draws its own simple badge (sun, mountains,
and valley in the Town's blue, navy, and gold) instead. Nothing else needs to
change; the file is picked up the next time the renderer is built.
